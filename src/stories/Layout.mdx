# Layout System

The layout system is built on a set of semantic size tokens and a single flexible primitive — `ElegantContainer`. Every spacing value in the UI maps to one of these tokens; hardcoded pixel values and `primitive-*` tokens are never used directly in layout code.

---

## Spacing tokens

These are the tokens you'll use for gaps, padding, and section rhythm. All values resolve to entries on the primitive scale.

## ElegantContainer

`ElegantContainer` is the only layout primitive. It renders as any block element and composes flex layout entirely through token-backed props — no raw CSS required in page code.

```tsx
import { ElegantContainer } from '@/components/simple/ElegantContainer';
```

### Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `as` | `div \| section \| article \| main \| aside \| header \| footer \| nav` | `div` | Rendered HTML element |
| `maxWidth` | `'page' \| 'full'` | — | `page` clamps to `--size-max-width` (1280 px) |
| `center` | `boolean` | `false` | Adds `margin-inline: auto` |
| `fullWidth` | `boolean` | `false` | Sets `width: 100%` |
| `paddingX` | `'none' \| 'gutter' \| 'card'` | `'none'` | Horizontal inner padding |
| `paddingY` | `'none' \| 'gutter' \| 'card' \| 'stack' \| 'section'` | `'none'` | Vertical inner padding |
| `gap` | `'none' \| 'tag' \| 'card' \| 'stack' \| 'section'` | `'none'` | Gap between direct children |
| `direction` | `'column' \| 'row' \| 'row-wrap'` | `'column'` | Flex direction |
| `align` | `'start' \| 'center' \| 'end' \| 'stretch'` | `'stretch'` | `align-items` |
| `justify` | `'start' \| 'center' \| 'end' \| 'between' \| 'around'` | `'start'` | `justify-content` |

## Nesting rules

Containers nest freely. The outer container controls page rhythm; inner containers control component-level layout.

```tsx
// Page section wrapper
<ElegantContainer
  as="section"
  maxWidth="page"
  center
  paddingX="gutter"
  paddingY="section"
  fullWidth
>
  {/* Heading + body group */}
  <ElegantContainer direction="column" gap="card">
    <h2>Section heading</h2>
    <p>Supporting description.</p>
  </ElegantContainer>

  {/* Card row */}
  <ElegantContainer direction="row-wrap" gap="card" fullWidth>
    <Card />
    <Card />
    <Card />
  </ElegantContainer>
</ElegantContainer>
```

## Token usage rules

- Use only `--color-*` and `--size-*` tokens in layout code.
- Never reference `--primitive-*` directly in component or page markup — primitives are the raw scale; semantics are the contract.
- Never hardcode hex values, pixel sizes, or font stacks.
- `--size-page-gutter` is the canonical horizontal padding for every page-level section. Do not substitute `--size-card-padding` at the page edge.
- `--size-section-gap` is for vertical rhythm between full-width page sections only — not between cards or stack items.
